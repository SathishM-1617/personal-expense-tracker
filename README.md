# personal-expense-tracker
A responsive web application designed to help users manage their personal finances by tracking income and expenses. 

Features :
  User registration and login 
  Firebase Authentication 
  Add and delete income and expense transactions 
  Automatic income and expense calculations
  Real-time balance tracking
  Cloud-Based data storage using firebase firestore
  User-specific transaction management

Tech Stack :
  HTML
  CSS
  JavaScript
  Firebase Authentication
  Cloud Firestore

Project Structure
  The project contains HTML pages, CSS stylesheets, Javascript files and Firebae configuration.

Getting Started 
  Clone this repository
  Open the project folder in Visual Studio COde
  Configure your Own Firebase project
  run the application using Live Server.

Security
  Firestore security rules restrict users to accessing their own expense records.
